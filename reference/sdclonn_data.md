# Function that returns a dataset

Function that returns a dataset

## Usage

``` r
sdclonn_data(dataset)
```

## Arguments

- dataset:

  Name of data set within the sdclonn package

## Value

data frame

## Examples

``` r
a <- sdclonn_data("synthetic_5000")

# Alle variabler med små bosktaver + variabel sektor3
```
